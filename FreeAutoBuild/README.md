# Free AutoBuild

A free, activation-code-free Geometry Dash Geode editor helper.

Current prototype:
- MODERN template
- TECH template
- GLOW template
- AI IDEA prompt that locally maps keywords to a template
- Android64 / Geometry Dash 2.2081

This is an original implementation, not a bypass or cracked copy of a paid mod.
The template system is local and does not require an activation code or external service.
